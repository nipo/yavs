yavs 0.15.0 makes long simulations run faster, adds one-command installers for Linux and Windows, and fixes a rejected signal attribute. A short first run of a few seconds may take longer than before.

- **Faster long simulations:** long runs, such as whole processors, run much faster, and a repeated run starts sooner. The performance page has the measurements.
- **Short first runs may be slower:** a first run of a few seconds can take longer than before. `YAVS_AUTO_POLICY=sampled` goes back to the earlier policy.
- **One-line installers:** `install.sh` (Linux) and `install.ps1` (Windows) install or update yavs without administrator rights.
- **`yavs-action`:** the continuous integration page shows its `variant: compat` input for runners without AVX2.
- **Bug fix (#1091):** a signal external name as the prefix of `'event` or `'last_event` is no longer rejected with `E1621`.


# Features

- Long simulations run faster, and a repeated run starts sooner.
- One command installs or updates yavs without administrator rights: `curl -fsSL https://raw.githubusercontent.com/ru551n/yavs/main/install.sh | sh` on Linux x86_64 and aarch64, and `powershell -c "irm https://raw.githubusercontent.com/ru551n/yavs/main/install.ps1 | iex"` on Windows x86_64. They choose the plain or the `-compat` archive for your CPU, check the download against the release's `SHA256SUMS`, replace a running installation safely, and ask before they add the directory to your `PATH`.

# Bug fixes

- A signal external name written directly as the prefix of a signal attribute, for example `<<signal .t.s : std_logic_vector(3 downto 0)>>'event` or `'last_event`, is no longer rejected with E1621: it behaves like the same signal read through an alias. (#1091)

# Documentation

- The continuous integration page shows `variant: compat` of `yavs-action` for runners without AVX2, instead of downloading the `-compat` archive by hand.

# Miscellaneous

- `--tier=auto` now also goes by how often code is entered when it decides what to compile, so a short cold run of a few seconds may take longer than before. `YAVS_AUTO_POLICY=sampled` goes back to the earlier policy.
