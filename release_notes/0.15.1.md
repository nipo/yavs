yavs 0.15.1 fixes valid designs that were rejected or ended in an internal error, mainly with external names and null arrays, and error messages now cite the LRM.

- **External names:** names in generate branches that are not elaborated no longer stop elaboration with "not implemented", and an alias declared in a process can name an instance elaborated after it.
- **More external name forms:** generic subprograms, protected methods, process constraints, block guards, signal initial values and nested package paths all work.
- **Null arrays:** slices of null arrays, static null operands, null array fields in port conversions and null slices in port maps no longer end in an internal error or a false rejection.
- **Wrong lengths are reported:** an element of the wrong length in a composite aggregate or generic value is now a length error. Some of these designs used to be accepted, so one may now report `E3009` or `E2115`.
- **Better messages:** many language-rule errors now cite the LRM clause they enforce.
- **Very large arrays:** an array of more than 2^64 - 1 elements is now error `E1406`.
- **Faster multipliers:** `numeric_std` `*` of short vectors runs much faster.



# Bug fixes

- An array or aggregate with more than 2^64 - 1 elements (for example two dimensions of 2^32 values each) is now reported as error `E1406` naming the dimensions, at analysis or at elaboration, instead of an internal error or a wrongly sized constant. A constant with a huge null dimension no longer makes analysis loop. (#1092)
- An external name that depends on a generic of a subprogram works in a process, for the subprogram's instances. (#1096)
- A method of a protected type declared in a process can assign an external signal. (#1097)
- A null array with constrained array elements can be assigned an aggregate. (#1098)
- The constraint of an object declared in a process or subprogram can name an external object. (#1099)
- An individually associated port can consist of null slices only. (#1100)
- A slice of an unconstrained formal in an individual association gives the formal its direction. (#1101)
- A block guard can read an external signal, and a signal's initial value can be the initial value of an external signal. (#1102)
- External names can use a package path through a nested package. (#1103)
- A port conversion of a composite with a null array field no longer ends in an internal error. (#1104)
- An element of the wrong length in a composite aggregate or generic value is a length error, not an internal error. (#1105)
- A slice of a null array as a signal name, port actual or assignment target no longer ends elaboration with an internal compiler error.
- An alias of an external name declared in a process can now name an instance elaborated after that process, instead of failing with `E2117`.
- Concurrent assignments with a static null operand, such as `y <= x when c = '1' else (others => '0');` on a zero-width vector or record field, no longer stop elaboration with an internal compiler error.
- External names used directly in a generate branch that is not elaborated (`if false`, a null `for` range, an alternative not chosen) no longer stop elaboration with "not implemented".

# Miscellaneous

- numeric_std `*` of two vectors whose product has at most 64 elements runs much faster, which helps filters, mixers and other designs built around multipliers. (#1095)
- Diagnostics for language-rule errors now cite the clause of the VHDL LRM they enforce in a note.
