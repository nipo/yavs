One command installs or updates yavs without administrator rights: `curl -fsSL https://raw.githubusercontent.com/ru551n/yavs/main/install.sh | sh` on Linux x86_64 and aarch64, and `powershell -c "irm https://raw.githubusercontent.com/ru551n/yavs/main/install.ps1 | iex"` on Windows x86_64. They choose the plain or the `-compat` archive for your CPU, check the download against the release's `SHA256SUMS`, replace a running installation safely, and ask before they add the directory to your `PATH`.
