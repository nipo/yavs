The x86_64 release archives (Linux and Windows) now need a CPU with AVX2 and the rest of x86-64-v3 (Intel Haswell, 2013, or AMD Excavator and Zen, or newer); on an older CPU `yavs` says which features are missing and exits with status 1. Each release also has a `-compat` archive for the two x86_64 platforms (`yavs-<version>-x86_64-unknown-linux-gnu-compat.tar.gz`, `yavs-<version>-x86_64-pc-windows-msvc-compat.zip`) that runs on any x86-64 CPU, and a build from source does too; the aarch64 archive is unchanged.
