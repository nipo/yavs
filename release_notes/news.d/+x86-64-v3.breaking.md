The x86_64 release archives (Linux and Windows) now need a CPU with AVX2 and the rest of x86-64-v3 (Intel Haswell, 2013, or AMD Excavator and Zen, or newer); on an older CPU `yavs` says which features are missing and exits with status 1. A build from source still runs on any x86-64 CPU, and the aarch64 archive is unchanged.
