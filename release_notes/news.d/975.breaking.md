Every path yavs writes is now dotted: report and assert lines read `Process tb.gen(1).u.p`, and so do runtime errors, diagnostics, `--print-hierarchy`, `--hang-report`, coverage reports and JSON output. Scripts that parse `Process :tb:p` need the new form. `'path_name` and `'instance_name` keep their LRM colons, and colon paths stay accepted wherever a path is typed.
