A protected type header can now hold a generic map after its generic clause, so `type t is protected generic (w : integer); generic map (w => 4); ... end protected;` declares a type ready to use, with constant, type, subprogram and package generics. Before VHDL-2019, a generic clause or generic map in a protected type is now rejected with a clear error instead of being accepted, and in VHDL-2019 a generic map with no generic clause is rejected instead of being ignored.
