`yavs lint` reports what can be proved wrong about a design before it is simulated: a process that can never suspend, a function that can fall through, unreachable statements, vector width mismatches, indexes out of range and division by zero, with configuration, waivers and JSON, SARIF, JUnit, Code Climate and SonarQube reports. Advisory, experimental and policy rules (latches, multiple drivers, combinational loops, state machines, clock and reset crossings, and more) run when a configuration asks for them, and `--facts` writes state machines and clock and reset domains as JSON. `exclude` in the configuration leaves files and directories out.
A waiver can turn rules off for whole directories and file patterns: `rule`, `files` and the new `files_exclude` each take a list, a plain directory covers everything under it, patterns are relative to the waiver file, `files_exclude` wins over `files`, and a pattern that covers no file gets a warning.
