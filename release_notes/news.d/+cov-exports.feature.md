`yavs cov report` writes a versioned JSON report with every kind and test (`--json`), an LCOV tracefile (`--lcov`) and a SonarQube generic coverage report (`--sonarqube`); the LCOV tracefile was checked with lcov 1.16, and the SonarQube report follows the published format and has not been read by a real scanner. `vunit-yavs` has `--yavs-cov-json`, `--yavs-cov-lcov`, `--yavs-cov-sonarqube` and `--yavs-cov-cobertura`.
