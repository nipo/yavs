An index constraint whose discrete range has another type than its index is now error `E1300` (LRM 2008 5.3.2.2: the type of each discrete range is the type of its index). This covers a type mark, a subtype, `t range a to b` and a range attribute, for example `sv(severity_level)` for an array indexed by `natural`; before, the declaration was accepted and a later use failed with a misleading error. Use a range of the index type. There is no `--relaxed` for this.
