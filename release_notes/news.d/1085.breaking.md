An explicit declaration with the name of the implicit signal `GUARD` of a guarded block (a signal, generic, port, constant, type, subprogram or alias called `guard` in the block) is now error `E1101` (LRM 2008 11.2, 12.3: the implicit signal is not a predefined operation, so an explicit homograph does not hide it). Rename the declaration. There is no `--relaxed` for this.
