The attributes `'range`, `'reverse_range`, `'length`, `'left`, `'right`, `'high`, `'low`, `'ascending`, `'subtype` and `'element` of a deferred constant with an unconstrained subtype can now be used in a package body, in subprograms (bodies, parameter subtypes, variables) and after its full declaration, with the bounds of the full declaration's value. The package declaration and the declarations of the body before the full declaration still report `E1226`.
A subprogram of a package body that reads the bounds of an unconstrained deferred constant and is called, to initialise a constant of the body, before the constant's full declaration is elaborated is now a run-time error (`E3009`) that names the constant and says to move the call below the full declaration, in every execution tier.
The bounds of an unconstrained deferred constant of a generic package instantiated in an architecture, block or process, which read as 1, and such a declaration in a process, which was an internal error, now report that this is not implemented yet.
