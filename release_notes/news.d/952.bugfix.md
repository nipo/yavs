A Surfer that stops answering, for example because its window is covered or minimized, no longer ends `--surfer` for the rest of the session: the Debug Console and the terminal prompt say so at once, `wave add` and Add to Wave answer within seconds and give the reason, and the view catches up when Surfer answers again. A closed Surfer is told when it happens, with its own message, a refused command no longer ends the connection, and a Surfer that does not answer at the end no longer holds up the exit.
