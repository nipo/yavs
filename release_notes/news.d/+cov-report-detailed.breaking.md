The default output of `yavs cov report` changes: a table of the kinds with items, hit, missed and coverage, a line per instance, then a count of what never ran and of what is excluded. `--detailed` is a debugging view per instance: a table per kind with every item, a table of the rows of each condition and expression with what the other inputs must be, and for what never ran the source underlined, what is missing, a tip, and the text that excludes it. `--below=PCT` keeps the instances under a percentage, worst first, so `--below=100 --detailed` shows what is left to do. `--uncovered`, `--tests`, `--exclusions` and the HTML report are unchanged. `vunit-yavs` has `--yavs-cov-below` and `--yavs-cov-detailed`. A rule whose items ran now warns once (`W0114`), with paths after `--root`.
