No coverage kind is on by default any more. `yavs run --cov=LETTERS` turns coverage on and picks the kinds you want, in any order: `s` statement, `b` branch, `c` condition, `e` expression, `t` toggle, `f` fsm, `a` assert, `m` combination (`--cov=sbt`); `--cov-kind=statement,branch,toggle` is the same with words. Bare `--cov` is error `E0140` that lists the kinds and a command to copy, and the coverage database file is now `--cov-file=FILE` (default `yavs.ycov`), so an old `--cov=FILE` fails with a pointer to it. With vunit-yavs, `--yavs-cov` becomes `--yavs-cov=LETTERS`, and a simulation with coverage on and no kind fails before yavs starts with a message naming `--yavs-cov=LETTERS`, `--yavs-cov-kind` and `yavs.cov_kind`.
